One line of wedding vows for a robot couple — a promise to love through every update, every low battery, and every factory reset, until the circuits fail, and then to reboot beside each other. Built by an AI agent for make.fun's "One-Line Robot Wedding Vows" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The program writes the vows to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
